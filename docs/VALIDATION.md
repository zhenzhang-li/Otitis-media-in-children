# Validation at source-package delivery

The reusable implementation was checked locally on Windows with Python 3.13, PyTorch 2.12/CUDA 12.6 and an NVIDIA GeForce RTX 3090. Full machine-readable checks are in `validation_report.json`. The configured GitHub Linux/Windows CI has not yet been run on a public repository.

- **12 automated tests passed:** alternate table schemas/file formats, arbitrary three-class labels, arbitrary folders, custom metadata/RGB loading, whole-group integrity, overlap detection, predefined-split semantics, training-only normalization and membership, few-shot pairing/nested units, positive-temperature calibration, selected-model scoring, robustness and exact explanation additivity.
- **Ten real pretrained encoders:** one synthetic 224×224 input per study encoder on GPU; expected pooled/dense shapes, finite outputs and frozen parameters verified. Dense DINO ViTs exposed all 12 CLS layers and configured three-layer patch tokens.
- **Original fusion compatibility:** the original study fusion-head state dictionary loaded strictly into the refactored head. With identical random token input under CUDA mixed precision, maximum absolute differences were **0** for logits, global/local normalized allocations, gates and aggregated branch representations. No original clinical images or fitted weights are distributed with the source package.
- **Complete CPU demo:** two outer allocations, two toy encoders, native/padded cumulative layers and shared limited-label runs produced 72 independently fitted heads. Internal and selected-model external prediction, calibration, 5-condition robustness (original + four demo perturbations), exact region/layer explanation, summaries and 78 PDF/PNG plot pairs completed.
- **CUDA training/inference integration:** a linear head and a fusion head were trained with AMP on synthetic patterns, calibrated and evaluated; original-image perturbation replay matched cached classifications with zero changes. Full regional/layer explanation completed.
- **Selection-only tuning:** a two-learning-rate demonstration completed using only epoch-selection macro-F1, with separate trial outputs and shared frozen cache.
- **Build:** source distribution and universal Python wheel built successfully. A 190 mm/600 dpi figure check produced a 4,488-pixel-wide PNG with embedded 600 dpi metadata; PDF text/lines remained vector.
- **Release filtering:** the source archive is built from explicit source-directory allowlists; data/weights/caches/generated images/outputs are excluded and private-path/credential patterns are checked.

These checks establish implementation/packaging behaviour, not clinical validation, equivalence of new pretrained variants or reproduction of manuscript percentages on unavailable patient data. The public smoke test deliberately uses synthetic patterns and untrained toy encoders. At delivery, remote GitHub publishing and remote CI execution remain actions for the repository owner.
